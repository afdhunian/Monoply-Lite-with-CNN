# RTL – Register Transfer Level

This directory contains the Verilog source code for the CNN hardware implementation.

The RTL modules are designed to implement the CNN inference architecture, including convolution, multiplication and accumulation (MAC), activation, pooling, dense computation, and classification.

All modules will be developed and verified incrementally before integration into the complete CNN hardware system.

## Planned Modules

- CNN Top Module
- Convolution Layer
- MAC Unit
- ReLU and Quantization
- Max Pooling
- Dense Layer
- Weight and Bias ROM
- Argmax
- Controller

## Development Platform

- FPGA: DE10-Standard
- HDL: Verilog
- Software: Intel Quartus Prime
