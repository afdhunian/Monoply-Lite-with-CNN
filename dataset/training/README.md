# Dataset Training

## Overview

This directory documents the dataset preparation and usage process for training the CNN model.

## Training Data Source

The training dataset is obtained from the Six-Sided Dice Images and Bounding Boxes dataset on Kaggle.

## Preparation Workflow

1. Download the original dataset in ZIP format.
2. Upload the ZIP file to Google Colab.
3. Extract the dataset.
4. Prepare the image data and corresponding XML annotations.
5. Use the prepared dataset in the CNN training notebook.

## Development Environment

- Python
- Google Colab
- TensorFlow / Keras
- NumPy
- Matplotlib

## Notes

The complete training dataset is not uploaded to this directory because of its large file size.

The original dataset is maintained separately and accessed through the Kaggle source.
